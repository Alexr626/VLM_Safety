# Flip-plot baseline reference — Alex clarification

**Date:** 2026-07-22

## Conclusion

There is no natural single “baseline flip count” to put as grey bars beside steering flip bars on the same pane. Leading-clause effect and steering effect are separate contrasts; comparing grey (neutral→leading) vs colored (leading→steered) heights is not meaningful.

## What Alex is actually exploring

1. **Leading-clause effect** on responses (accuracy, answer changes, P(yes)/P(no))
2. **Steering effect** on responses (same metrics)

These are better read from separate panes / contrasts (neutral vs assertive for prompt; within-condition baseline vs steered for intervention), not from overlaying both as competing bars on the flip plot.
